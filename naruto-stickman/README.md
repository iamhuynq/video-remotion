# Naruto Stickman Walk — Remotion

A simple Remotion starter that assembles SVG character parts and animates a procedural walk cycle using `useCurrentFrame()` and trigonometric motion. No AI-generated motion.

## Run
```bash
npm install
npm run start
```

## Render
```bash
npm run render
```

Output: `out/naruto-walk.mp4`. Composition: 1080x1920, 30 FPS, 10 seconds. This is a prototype; tune SVG placement and pivots for smoother joints.
